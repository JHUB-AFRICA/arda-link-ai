# ArdaLink — Marketing

Public-facing collateral for the ArdaLink project: conference posters
and a static showcase website. Lives inside the public monorepo at
<https://github.com/JHUB-AFRICA/arda-link-ai> as a sibling to the three
service apps.

## Poster

| File | Size | Use |
|---|---|---|
| `poster/poster-A0.pdf` | 841 × 1189 mm (A0 portrait) | Conference / exhibition wall |
| `poster/poster-letter.pdf` | 11 × 17 in (Tabloid) | Academic poster session |

The `.svg` files are the editable source — open in Inkscape / Figma /
Illustrator to tweak copy or layout. Both are generated by
`poster/build_posters.py` from the same brand tokens used by the
website.

Rebuild a PDF from SVG:

```bash
rsvg-convert -f pdf -o poster/poster-A0.pdf poster/poster-A0.svg
rsvg-convert -f pdf -o poster/poster-letter.pdf poster/poster-letter.svg
```

Or regenerate from source:

```bash
python3 poster/build_posters.py
```

## Website

Static, no build step, no framework. Open `site/index.html` directly,
or serve it with any static host (GitHub Pages, Netlify, Cloudflare
Pages, `python3 -m http.server`, etc.).

Quick local preview:

```bash
cd site && python3 -m http.server 8080
# → http://localhost:8080/
```

Hero, channel, and diagram SVGs are generated by
`site/assets/build_illustrations.py` — original on-brand illustrations
(satellite beams, phone/chat mockups, iconographic flow diagrams), not
photography. Re-run that script to refresh after editing copy or brand
tokens. Team headshots (`team-*.svg`) are a distinct, intentionally
tentative "photo pending" avatar style, since real photos of real
people can't be generated — swap those for real headshots when
available. The old `build_placeholders.py` (literal "PLACEHOLDER —
replace before launch" cards) is superseded and no longer used.
